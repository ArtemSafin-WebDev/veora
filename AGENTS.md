# Правила вёрстки

- HTML-страницы создавайте в корне проекта рядом с `index.html`, без вложенных папок. Данные страниц храните в соответствующих файлах `src/data/pages/<имя>.json`.
- Во всём проекте отключайте `outline`. Не добавляйте рамки через `outline` для `:focus` или `:focus-visible`, в том числе кнопкам, ссылкам и полям.

- При вёрстке по макетам корневой размер шрифта — `10px`: `1rem = 10px`.
- Размеры шрифтов, отступы, ширины, высоты, скругления и другие фиксированные размеры задавайте в `rem`.
- Точки перелома в медиавыражениях задавайте в `px`.
- Адаптивную вёрстку делайте только для мобильных экранов. Если соответствующего макета нет, не добавляйте адаптив без прямого указания.
- Толщину ровно в один пиксель задавайте как `1px` (например, границы). Не заменяйте её на `0.1rem`.
- Верстайте покомпонентно по БЭМ: самостоятельный компонент или секция — отдельный блок, внутренние элементы и модификаторы называйте по БЭМ.
- Иконки выводите как SVG: инлайново или через SVG-спрайт. Не используйте `<img>` для иконок, в том числе стрелок, галочек и кнопок закрытия. Переиспользуйте общий компонент `icon` и спрайт проекта.
- Фоновые фотографии секций выводите через `<img>` или `<picture>`, а не через `background-image`. Картинка должна универсально заполнять контейнер: `width: 100%`, `height: 100%`, `object-fit: cover`; при абсолютном позиционировании используйте `inset: 0`. Не подгоняйте её под конкретный макет смещениями `left`/`top`, отрицательными отступами, увеличенными размерами, трансформациями или инлайновыми параметрами геометрии. Для отдельного мобильного изображения используйте `<source>` внутри `<picture>`.
- `background-image` допускается только в редких случаях для декоративных элементов, например текстур и свечений.
- Для каждого компонента и каждой секции создавайте отдельный SCSS-файл рядом с его шаблоном.
- Переиспользуемые элементы храните в `src/components/`, крупные секции страниц — в `src/sections/`. Секции также считаются БЭМ-блоками.
- Вертикальный ритм секций на сайте задавайте через `margin-bottom` у секций.
- Тексты и параметры страниц храните отдельно от шаблонов в `src/data/`.
- В проекте две цветовые схемы страниц: бежевая и тёмно-синяя. Цветовую схему страницы задавайте через класс на `body`.
- Верстаем с расчётом на сайты Битрикс24: результат сборки должен оставаться статическими HTML, CSS и JavaScript, пригодными для переноса в эту среду.
