# Правила вёрстки

- При вёрстке по макетам корневой размер шрифта — `10px`: `1rem = 10px`.
- Размеры шрифтов, отступы, ширины, высоты, скругления и другие фиксированные размеры задавайте в `rem`.
- Точки перелома в медиавыражениях задавайте в `px`.
- Адаптивную вёрстку делайте только для мобильных экранов. Если соответствующего макета нет, не добавляйте адаптив без прямого указания.
- Толщину ровно в один пиксель задавайте как `1px` (например, границы). Не заменяйте её на `0.1rem`.
- Верстайте покомпонентно по БЭМ: самостоятельный компонент или секция — отдельный блок, внутренние элементы и модификаторы называйте по БЭМ.
- Для каждого компонента и каждой секции создавайте отдельный SCSS-файл рядом с его шаблоном.
- Переиспользуемые элементы храните в `src/components/`, крупные секции страниц — в `src/sections/`. Секции также считаются БЭМ-блоками.
- Вертикальный ритм секций на сайте задавайте через `margin-bottom` у секций.
- Тексты и параметры страниц храните отдельно от шаблонов в `src/data/`.
- Верстаем с расчётом на сайты Битрикс24: результат сборки должен оставаться статическими HTML, CSS и JavaScript, пригодными для переноса в эту среду.
